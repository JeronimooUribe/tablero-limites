# Límites · Técnica Navegación

Tablero para aprender a **resolver** límites, pensado para el examen del profesor Nelson Uribe.

- **Árbol de decisión:** qué hacer según lo que salga al sustituir.
- **10 tipos:** cada uno con su receta, ejemplos paso a paso, un ejercicio para completar, trampas y videos de Julioprofe.
- **Entrenar:** ejercicios infinitos con corrección inmediata. Los que fallas vuelven.
- **¿Qué tipo es?:** practicar reconocer el método.
- **Simulacro:** 10 ejercicios en 20 minutos, con nota sobre 5.0.

Todas las respuestas se verificaron con sympy: 21 ejemplos y 450 ejercicios generados.
